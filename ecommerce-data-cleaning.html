E-commerce Data Cleaning

Excel Data Cleaning & Data Quality Project

Project Overview

This project focuses on cleaning and validating an e-commerce sales dataset using Microsoft Excel.

The dataset contains approximately 50,000 sales records along with customer, product and store information.

Tools Used

Excel • XLOOKUP • Filters • Tables • PivotTables • Data Validation

Data Cleaning Process

Raw Data → Data Inspection → Cleaning → Validation → Final Dataset

  • Checked duplicate transaction IDs
  • Checked missing customer IDs
  • Checked missing discount values
  • Validated product IDs using XLOOKUP
  • Validated store IDs
  • Checked quantity values
  • Checked date completeness

Example: Product ID Validation

XLOOKUP was used to compare product IDs in the sales data with the product master table.

The check identified P99999 as a product ID that was not found in the product table.

Instead of deleting the record, it was flagged for further investigation.

Final Summary

  • 50,000 sales records were reviewed.
  • No duplicate transaction IDs were identified.
  • 1,844 missing customer IDs were identified and flagged.
  • 2,583 missing discount values were identified for investigation.
  • Product ID P99999 was not found in the Product Data table.
  • Store ID S999 was not found in the Store Data table.
  • Quantity and date fields passed the initial validation checks.
Next Step: Integrate Sales Data with Customer, Product, and Store Data for further analysis and reporting.
